🇦🇴 Odoo 17 – Integração de Facturação Electrónica (AGT)

Autor: Digitalub / ContasMais
Versão: 1.0.0
Compatibilidade: Odoo 17
Licença: AGPL-3

Descrição: O módulo l10n_ao_fe implementa a integração direta entre o Odoo 17 e o sistema de Facturação Electrónica da AGT, com suporte para assinatura digital, comunicação REST e geração do QR Code oficial exigido nos documentos fiscais.

🧭 Funcionalidades

  • Assinatura Digital (RS256) usando chave privada RSA
  • Integração completa com os serviços AGT (registarFactura, consultarFactura, listarFacturas, etc.)
  • Fila de envio automática (l10n_ao.fe.queue)
  • Geração automática do QR Code conforme as normas da AGT
  • Compatível com Factura, Factura-Recibo, Recibo Geral e Nota de Crédito

🔑 Geração de Chaves RSA

cd /etc/odoo/
openssl genrsa -out ChavePrivada.pem 2048
openssl rsa -in ChavePrivada.pem -outform PEM -pubout -out ChavePublica.pem

🧠 Fluxo Operacional

  1. Emitir e validar a fatura no Odoo.
  2. Clicar no botão “Enviar AGT”.
  3. O sistema cria um JSON conforme o esquema DS-102 e DS-120 da AGT.
  4. Assina digitalmente e envia via REST API (registarFactura).
  5. Recebe o identificador e atualiza o estado na fila (FEQueue).
  6. Gera o QR Code da AGT no documento impresso (33x33 módulos, UTF-8, PNG).
